## Reproduce On The Pi

From the deployed project root:

```sh
python3 -m compileall -q piboard tests
python3 tests/smoke_v0_1_1.py
python3 tests/smoke_visual.py
mkdir -p .visual-review/v0.1.2/tmp
TMPDIR="$PWD/.visual-review/v0.1.2/tmp" python3 -m unittest discover -s tests -p 'test_*.py'
python3 tests/pi_release_acceptance.py --switch-pages
```

The helper is opt-in: it temporarily changes selected pages and the mock preset, restores them even on errors, and refuses output outside the project. It requires the pre-release private backup `.visual-review/v0.1.2/state.before.json`; it does not create or publish a private state snapshot. To repeat against a different baseline, explicitly take a new project-local backup rather than overwriting this release's rollback copy.

## Known Issues

- Train live: public upstream HTTP 500, visibly WAIT/unavailable. This external outage remains unresolved and explicitly not a successful live acceptance.
- iCal RRULE/exceptions and cross-day coverage remain incomplete; the private feed fetch check does not certify all calendar semantics.
- Optional OpenWeatherMap summary compatibility and multi-controller settings overwrites remain; use the default Open-Meteo path and one settings controller at a time.
- Trusted-LAN console only: no authentication, API state can contain secrets. Type/enum validation is not authentication, full business validation or an Internet security boundary. Browser location needs a secure origin; manual city remains available over LAN HTTP.
- Historical <3% static CPU/<80MB goals are not fully met; no performance redesign or system package changes in this release. Physical viewing/optical blur and a long soak remain outside automated certification.
